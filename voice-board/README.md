# Voice Board (MVP)

Monorepo with a minimal React web app + Node API.

## Prereqs
- Node.js 18+ (recommended 20+)

## Setup
```bash
cd voice-board
npm install
```

## Run (dev)
```bash
npm run dev
```
- Web: http://localhost:5173
- API: http://localhost:3001

## Environment
- Set `OPENAI_API_KEY` (see `.env.example`).

## Data
- JSON files live in `data/db/`
- Policy docs live in `data/policies/`
